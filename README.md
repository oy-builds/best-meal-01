# The Best Meal You Ever Had

A tiny TypeScript program that writes one sentence to `/output/entry.txt`:
the best meal I ever had, as one concrete memory. Past midnight on a
plastic stool in Yogyakarta, my grandmother slides me nasi goreng crackling
from the wok — yolk gold over the rice, chilli smoke in my eyes — and
hunger ends like a breath let go.

Run with `node main.ts` (Node 22+).
